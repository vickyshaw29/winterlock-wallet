# winterlock-wallet

PQ Wallet using ERC-8250 (Keyed Nonce) and EIP-8141 (Alt-Mempool).

## Known limitations

- An account is a 45-byte EIP-1167 proxy, so every call to it, a plain ETH payment included, runs a DELEGATECALL to the implementation (about 2,700 gas with a cold implementation). It cannot receive ETH from a contract that forwards only the 2,300-gas stipend (Solidity's `transfer` and `send`); a plain `call` with value works.
